# Project Atlas Roadmap

Status reflects this repository at the end of the foundation phase.

| Phase | Status | Scope |
| --- | --- | --- |
| 0. Foundation | **Completed** | Next.js base, typed data registry, conventional pages, opt-in 3D hub, player, interaction, generic exhibits, docs, and handoff. |
| 1. Portfolio Core | **In progress** | Lyrune is complete as the first verified case-study/reference integration; next, complete owner content, resume links when available, more verified case-study media, conventional accessibility review, and an intentional visual identity pass. |
| 2. Major Project Exhibits | **Started** | Lyrune has a labeled, data-configured flagship exhibit in the current hub. A richer software-lab presentation and the Kerala command center remain deferred until their content and assets are ready. |
| 3. World Expansion | Deferred | Add separately loaded districts for application, intelligent, and interactive systems; create area navigation and transitions. |
| 4. Interactive Demonstrations | Deferred | Introduce focused demo renderers/experiences for video, simulation, external tools, and later playable web prototypes. |
| 5. Optimization | Deferred until representative content exists | Asset pipeline, area loading, profiling budgets, model/texture compression, and quality tiers based on measurements. |
| 6. Visual Polish | Deferred | Art direction, final materials, sound, animation, accessibility equivalents, and interaction refinement. |
| 7. Deployment and Analytics | Deferred | Hosting, privacy-conscious analytics, error monitoring, SEO assets, performance monitoring, and deployment documentation. |

## Recommended next task sequence

1. Confirm the portfolio owner’s factual copy, links, project status, images, and resume destination; update only verified project records.
2. Apply the Lyrune case-study pattern to the next verified project; keep its content inside a typed record.
3. Define target devices and art direction, then establish measurable 3D budgets before importing final assets.
4. Add a richer exhibit presentation only when its project has verified content/assets to support it.
5. Add a lazy second world area only when there is enough content to justify it.

## Intentionally deferred

Final environment art, third-person character animation, collision physics, world streaming, graphics settings, multiplayer, authentication, database/CMS infrastructure, a complete PvP game, final playable demos, deployment analytics, and a full asset pipeline are deliberately outside this foundation.
