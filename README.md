# Project Atlas

Project Atlas is a web-native, progressively enhanced portfolio foundation for software, intelligent systems, and interactive work. The conventional Next.js site works independently; visitors can explicitly launch an optional React Three Fiber prototype hub.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Validate before handing work over:

```bash
npm run typecheck
npm run build
```
